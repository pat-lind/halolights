Project from 6 years ago from an account I also lost (original project https://github.com/sisyphusatlas/halolights),
Here I re-upload it to this account.

The project included 9 esp8266's, programmable microcontrollers with wifi capabilities, installed on 9 round circles OSB board carved with with a router attached with addressable LED's  glued and soldered on the bottom. 

The project takes a single camera to estimate depth with an old depth estimating image model, to turn on a light depending on where someone stood in a 3x3 grid.  

### "halolights" : 
 
Download pretrained NYU.h5 model from https://github.com/ialhashim/DenseDepth and add it to main directory.

RUN MAINLOOP IN
